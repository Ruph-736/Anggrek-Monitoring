Koneksi MQTT dari Browser (Opsional)

Secara default dashboard menampilkan data terkini dari Firebase. Jika ingin menerima pesan MQTT setiap 10 detik, masukkan kredensial read-only EMQX khusus dashboard. Username dan password hanya disimpan selama tab dibuka.

Isi MQTT_WSS_URL di config.js dahulu. Jangan gunakan kredensial admin EMQX.

Arsip Bulanan (CSV)

Pilih bulan, unduh semua data log mentah dan agregat per jam dalam satu CSV. Setelah memastikan file backup tersimpan, log mentah bulan yang sudah lebih dari 90 hari boleh dihapus. Ringkasan per jam tidak dihapus sehingga grafik bulanan tetap berfungsi untuk periode tersisa.

Penghapusan hanya tersedia setelah backup pada sesi browser ini dan hanya untuk bulan yang berakhir lebih dari 90 hari lalu.

Perhatian: backup CSV tersimpan di perangkat/browser, bukan otomatis di Firebase atau Cloud Storage. Simpan salinan tambahan di drive komputer/penyimpanan pribadi sebelum hapus data.
